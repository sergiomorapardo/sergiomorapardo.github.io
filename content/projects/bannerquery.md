BannerQuery was an early Python packaging project built to simplify queries against Ellucian Banner databases.

## Why it belongs here

The project documents an earlier stage of my path: turning repeated analytics work into a reusable interface, publishing a package, and learning the operational details of Python distribution.

The original release referenced version `0.0.2`. That version is preserved as historical context rather than presented as a currently maintained production dependency.
